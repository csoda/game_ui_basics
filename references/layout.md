# ゲームUI配置ガイド

まず一文：「この表示を見た直後、プレイヤーは何をする？」。次に、常時見返す情報、判断が必要になった時だけ出す情報、別画面で十分な情報へ分ける。

## プレイ中のHUD

| テクニック | 試し方 |
| --- | --- |
| 01 よく見る場所のすぐ外 | 回避先・照準・次の地形を隠さない。そのすぐ隣に、次の判断に使う表示を出す。 |
| 02 一緒に読む数字を寄せる | 帰るか迷うなら「燃料36%」と「帰還目安30%」は同じまとまりに。帰還に無関係な鉱石数は離す。 |
| 03 何度も確認する情報は定位置 | HPや弾数は再確認のたびに探させない。状況によって隠すなら再表示の条件と位置を統一する。 |
| 04 その場限りの操作は対象のそば | 掘れる鉱脈や拾える品の近くに短いプロンプト。候補が複数なら、入力が効く一つに絞る。 |
| 05 見えない方向は画面の縁 | 画面外では方向付きの印。対象が画面内に入ったら現地の範囲表示へ引き継ぐ。別々の危険に見せない。 |
| 06 背景の明暗どちらでも読めるように | 夕日、暗所、粉塵の上で確認。文字・形・縁取りで判別できるようにし、色だけで区別しない。 |

## メニューと入力

| テクニック | 試し方 |
| --- | --- |
| 07 まず一番よく使う操作を見つける | プレイヤーが取る主な行動がひと目で分かるようにする。同じ重さのボタンが並ぶなら、頻度と目的で優先度をつける。 |
| 08 余白で項目を分ける | 同じ判断に必要な情報は近く、別の操作とは距離を取る。何でも枠に入れる前に、間隔と整列で試す。 |
| 09 戻る場所と入力は引っ越させない | 各画面で戻る動作を同じキーと同じ場所で見つけられるようにする。閉じた後の選択位置も元へ戻す。 |
| 10 押しやすさと指による遮りを別に見る | 利き手で握り、長押しと同時入力を試す。親指で次の敵や照準を隠さず、OSのジェスチャー領域とも競合させない。 |
| 11 フォーカスと選択済みを別の印に | ゲームパッドで次に操作する対象と、すでに装備・選択した項目を区別する。十字キーの向きどおりに移動するかも見る。 |
| 12 狭いときは優先度順に整理する | 幅が足りなくても操作と意味のある数字を潰さない。折り返し、行を増やす、低頻度情報を別画面に送る順で検討する。 |

## 例：掘り進むか、帰るか

次の地層に視線が向くなら、進行方向そのものは空ける。燃料と帰還ラインは同じ場所に、鉱石数は別の場所に置く。警告の位置変更を試すときは、同じ地形・消費量で「いつ帰ると判断した？」を見る。スクリーンショットから実際のプレイ成績までは判断しない。
