# ほしくず回収便：ゲームで使ったUI演出

[単体HTML](../docs/punipo/index.html)をブラウザで開くと遊べます。スマホは画面内を左右にドラッグ、PCはドラッグまたは ← → / A D。ブーストはボタンまたは Space。PUNIPOに投稿する場合はHTMLだけを選んでください（[投稿ガイド](https://punipo.com/for-creators)）。

50秒で帰還する回収ゲームです。岩を避けつつ鉱石を続けて取ると倍率が上がります。離れた場所に出る紫の鉱石は高得点。18秒・34秒で磁石／装甲／電池からひとつ選びます。ブースト中は岩を砕けて得点も2倍になりますが、流れが速くなります。

## カタログと見比べる

下表はゲーム中に確認できる10種。完全に同じ形でない箇所は「応用」と記しました。ゲーム画面には技法名や番号は出していません。

| ID | 場面 | ゲーム中で見えるもの |
| --- | --- | --- |
| 001 | ボタンを押す | ボタン本体が沈み、足元の影が縮む。 |
| 012 | キーボードで強化候補を移る | 外側の黄色い枠は現在のフォーカス。選択確定とは別。 |
| 021 | 機体改造が開く | コースを暗くし、改造パネルだけを下から短く出す。 |
| 031 | 機体改造の3択 | 磁石・装甲・電池がごく短い時間差で並ぶ。 |
| 042 | 航行中（応用） | 帰還までの進行バーに2つの改造地点。通過すると改造ウィンドウが開く。 |
| 043 | 装甲を選んで被弾 | シアンの装甲層が機体の耐久表示に重なる。岩に当たると先に装甲が消える。 |

ほかにも「ランク境界を表示し、計算後に到達ランクが出る」「強化した箇所だけ一瞬囲う」を入れていますが、カタログの動きと異なるため上の件数には含めていません。

## PUNIPO向けの動作

- すべて描画・合成音で、外部読み込みなし。音は初期OFF。音声機能は操作を受けて初めて作成。
- ゲーム内の結果演出が終わったら、数値スコア付きの `gameOver` を親フレームに1回送り、描画を止める。再プレイボタンは単体で開いたときだけ表示。
