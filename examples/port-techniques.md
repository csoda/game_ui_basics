# ほしみなと管制局：ゲームUI 53種

[PUNIPOで遊ぶ](https://punipo.com/g/789) · [ブラウザ試遊版](https://csoda.github.io/game_ui_basics/port/) · [単体HTML](../docs/port/index.html) · [演出カタログ](../references/motion-patterns.md)

到着便をドックへ案内し、必要な資材を積み、出港させる70秒のブラウザミニゲーム。燃料・荷物・修理に対応する印のドックは作業が速い。資材を2個使う優先補給は早くて高得点ですが、在庫切れを招きます。出港で得たクレジットは補給倉へ。

最初の便は練習です。光っている船 → ドック → 給油 → 出港の順に押すだけ。カウントダウンや消費はなく、練習の出港後から通常の70秒が始まり、補給倉と航海手帳が開きます。本番の先頭は箱の船。船・ドック・在庫・作業画面は同じ形を使い、形の合う空きドックは短い接続線と短いバーで示します。違う形の空きドックも接岸可能。

1. **管制席**：船を選んでドックを押すか、直接ドラッグ。船が着いたらドックの「補給 1」を押し、出港印が出たら送り出します。通常補給は別画面を開きません。仕入れの確認はタップ・長押しのどちらでも確定できます。Tab / Enter にも対応。
2. **ドック**：「優先…」で通常／優先の消費・作業時間・得点を比較。在庫が足りなければ「あと何個」から該当する仕入れ確認へ。購入後も取消後も同じ船・同じ作業案に戻り、補給は別に確定します。比較と仕入れを開いている間はシフト時計が一時停止します。
3. **航海手帳**：現在の運行を止めて、目標、時系列の履歴、達成印を見る。直近のシフトをめくる例は、単体HTMLで同じタブ内から繰り返しプレイすると試せます。ブラウザやPUNIPOがゲームを読み直すと記録は消えます。

PUNIPO用には単体HTMLだけを使用。外部読み込み・外部保存なし。計算とランク表示を見せてから数値の `gameOver` を親フレームへ1回だけ送り、描画を止めます。投稿ガイドは[PUNIPO公式](https://punipo.com/for-creators)。
